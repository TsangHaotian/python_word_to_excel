# Word to Excel Automation Tool 📄➡️📊

A GUI-guided Word document processing tool that allows users to batch export content from specified Word documents directly into Excel.

## 🌟 Key Features

- **Smart Pop-up Guidance**: Provides full visual operational guidance throughout the process.
- **Batch Document Processing**: Supports converting multiple files simultaneously.
- **Automatic Format Recognition**:
  - Identifies headings and body text styles.
  - Extracts table data accurately.
  - Captures content marked with special symbols.
